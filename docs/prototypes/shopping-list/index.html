No real-time push in V0.1: this phone sees other changes only on load, refresh or reconnect.

State after the last action

    Locked flow (variant A)

    • One row per ingredient, grouped by aisle in a fixed walk order. Empty aisles are hidden.
    • The whole row is the tap target (at least 60px). Ticked rows fade, then move to "In the basket" so the next item stays at the top. Undo sits in the thumb zone.
    • Always-have items start ticked and live in "At home". Untick one and it returns to its aisle.
    • Unquantified lines show no amount ("to taste" in the source line), or "+ some" after a merged amount.
    • "Serve with" carbs appear as unquantified rows marked "serve with".
    • Offline: a banner and a count of ticks saved on the phone. Reconnect sends them, then reloads. Later tick wins per item.
    • Plan changes keep ticks by ingredient, except an item whose amount went up, which unticks and shows what it was.
